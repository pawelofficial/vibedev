## Project: `flask-calculator`

### File breakdown

| File | Role |
|---|---|
| `calculator/engine.py` | Pure-Python `Calculator` class — safe `eval`, history, sanitisation. No Flask dependency. |
| `calculator/extensions.py` | Shared singleton `calculator` instance (avoids circular imports). |
| `calculator/routes.py` | Flask `Blueprint` with 4 endpoints: `GET /`, `POST /calculate`, `GET /history`, `POST /clear-history`. |
| `calculator/app.py` | `create_app()` factory — registers blueprint, sets secret key. |
| `calculator/static/style.css` | Glassmorphism dark theme — CSS custom properties, 4-col button grid, animated button presses, responsive history sidebar. |
| `calculator/static/script.js` | `CalculatorUI` ES6 class — keyboard bindings, `fetch()` AJAX calls, history panel rendering, error flash. |
| `calculator/templates/index.html` | Jinja2 template — display `<input>`, `data-value` button grid, collapsible history `<ul>`. |
| `run.py` | Entry point — `create_app()` + `app.run()`, reads `RUN_DEBUG`/`PORT` from env. |

### Key design decisions
- **No circular imports** — `extensions.py` holds the singleton; routes import from it; the factory imports routes.
- **Safe eval** — only `math` module globals exposed; any import/exec tokens raise `ValueError` → HTTP 400.
- **All logic is AJAX-driven** — the HTML page never reloads; JS `fetch()`es every operation.
- **Dependency order is acyclic**: `engine → extensions → routes → app → run.py`.
