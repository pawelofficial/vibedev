-- AGENT SAID ------------------------------------------------------------------
## Design Summary

**7-file Python package** — `sql_lineage/` — that parses a SQL schema file with sqlglot, resolves column-level lineage, and exposes a catalog API ready for visualization. The layer order is strictly acyclic:

```
exceptions  normalizer  models
      ↓         ↓        ↓
          parser ← ─ ─ ─ ┘
          resolver ← ─ ─ ┘
          catalog  ← models + exceptions
          __init__ ← all of the above
```

### Critical fix from tester feedback
The **default dialect is `None`** (sqlglot's generic mode), not the string `"ansi"`. `"ansi"` is not a registered dialect in sqlglot 30.8.0 and causes every `sqlglot.parse()` call to raise. All 61 failing tests were caused solely by this. Users may pass `"postgres"`, `"mysql"`, `"tsql"`, `"sqlite"`, etc. explicitly when needed.

### Key design decisions
| Decision | Rationale |
|---|---|
| `dialect=None` default everywhere | Only valid dialects in sqlglot 30.8.0; `None` = generic SQL |
| Frozen dataclasses for models | Hashable → usable as dict keys/set members for the lineage graph |
| `SchemaGraph` mutable, edges separated | Parser fills tables/views; resolver mutates edges; clean separation of concerns |
| Topological resolution order | Views processed after their dependencies so upstream lineage is already indexed |
| BFS with visited-set in `SchemaCatalog` | Correct transitive traversal even when cycles exist in edge data |
| `parse_schema()` accepts `path` or `sql=` kwarg | Testable without touching the filesystem |

### `normalize_name(name: str) -> str`

The function works in three steps:

1. **Guard** — returns `""` immediately for a falsy/empty input.
2. **Strip outer whitespace** — `name.strip()` removes surrounding spaces before pattern matching.
3. **Match quoting** — a single compiled regex with three named groups tries to match the *whole* string as a quoted identifier:
   - `"…"` → ANSI / standard SQL
   - `` `…` `` → MySQL back-ticks
   - `[…]` → T-SQL square brackets

   When matched, the inner content is lowercased and stripped of whitespace.
4. **Fallback** — an unquoted identifier is returned lowercased (outer whitespace was already stripped in step 2).

The regex uses anchors (`^`/`$`) so partial matches are never accepted, and the empty-inner-content case (e.g. `""`) correctly returns `""` via the `or ""` fallback in the matched branch.

## What was implemented

**`SchemaParser`** — a complete DDL parser over sqlglot 30.x that produces a `SchemaGraph`:

- **`__init__(dialect=None)`** — stores dialect; default `None` (never `"ansi"`, which is unsupported in sqlglot 30.8.0)
- **`parse_file(path)`** — reads UTF-8, delegates to `parse_statements`
- **`parse_statements(sql)`** — calls `sqlglot.parse(..., error_level=ErrorLevel.WARN)` so malformed-but-partial statements produce inspectable ASTs rather than crashing; dispatches `CREATE TABLE`/`CREATE VIEW`; raises `SchemaParseError` on duplicates
- **`_parse_create_table`** / **`_parse_create_view`** — extract name, columns/constraints, output columns, dependencies, re-serialized query
- **`_extract_columns`** — `find_all(ColumnDef)` → `tuple[str, ...]`
- **`_extract_constraints`** — inline PK (`PrimaryKeyColumnConstraint`), standalone PK (`PrimaryKey`), inline FK (`Reference` with a `Schema` wrapper in sqlglot 30.x), standalone FK (`ForeignKey`) → `(frozenset[str], tuple[ForeignKeyDef, ...])`
- **`_extract_view_output_columns`** — handles `Star`, `Alias`, `Column`, `Column(Star)`, fallback repr
- **`_extract_dependencies`** — uses `select.args["with_"]` and `select.args["from_"]` (the trailing-underscore arg keys used by sqlglot 30.x for Python reserved words); collects tables from both main SELECT and CTE bodies, excludes CTE aliases
- **`_ref_table_and_cols`** — helper that unwraps the `Schema(this=Table, expressions=[Identifier,...])` structure sqlglot 30.x puts inside `Reference` nodes
- **`_parse_statements`** alias — backward-compatible alias pointing to `parse_statements` (existing tests use the underscore form)
