### `LineageResolver`

**`__init__`** — stores `dialect` (defaults to `None`, never `'ansi'`).

**`resolve`** — calls `_topo_sort_views` then walks every view in dependency order, delegating to `_resolve_view`. Raises `CircularDependencyError` if a cycle is detected.

**`_topo_sort_views`** — Kahn's algorithm over the view-only sub-graph. Tables are treated as roots (excluded from the sort entirely). If any view remains unprocessed after the queue drains, a `CircularDependencyError` is raised with the remaining node names.

**`_resolve_view`** — re-parses `view.query` via `sqlglot.parse_one(view.query, dialect=self.dialect)`, finds the `SELECT` node (even when wrapped in a `CREATE VIEW`), builds the alias map, then for each output expression either:
- expands a wildcard via `_handle_wildcard` (qualified `t.*`, single-source `*`, or stores a `column='*'` placeholder for ambiguous cases), or
- calls `_node_to_ref` on the unwrapped expression and pairs the result with a target `ColumnRef(view.name, output_col)`.

**`_build_alias_map`** — iterates `FROM` and all `JOIN` sources; handles `exp.Table` (with or without `.alias`), `exp.Alias`-wrapped tables, and `exp.Subquery` (alias self-mapped). All identifiers normalized.

**`_node_to_ref`** — handles `exp.Column` only. With a table qualifier: looks up in `alias_map`, falls back to direct graph lookup. Without a qualifier: infers from a single-entry `alias_map`, or searches all canonical names for the column; returns `None` on ambiguity so the caller silently skips.

**`_output_column_name`** — returns alias > column name > `'*'`, normalized.
